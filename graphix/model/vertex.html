Vertex

Vertex<T> représente un sommet du graphe. Il est générique : le paramètre T est le type de l'information portée par le sommet (un nom, un numéro, une structure…).

Définition​

src/model/vertex.rs
#[derive(Debug, Clone, PartialEq)]
pub struct Vertex<T> {
    pub id: T, // Information stockée par le sommet
}

Champs​

ChampTypeVisibilitéDescription
idTpubInformation stockée par le sommet. Malgré son nom, ce n'est pas l'identifiant interne du sommet (voir ci-dessous).

Traits dérivés​

TraitEffet
DebugAffichage avec {:?}, par exemple Vertex { id: "Paris" }. Nécessite que T: Debug.
CloneCopie explicite avec .clone(). Nécessite que T: Clone.
PartialEqComparaison avec == : deux sommets sont égaux si leurs id sont égaux. Nécessite que T: PartialEq.
Bornes conditionnelles

Les traits dérivés ne s'appliquent que si T les implémente aussi. Un Vertex<T> fonctionne avec n'importe quel T, mais on ne pourra l'afficher, le cloner ou le comparer que si T le permet.

Méthodes​

Vertex::new​

pub fn new(id: T) -> Self

Crée un sommet portant l'information id.

ParamètreTypeDescription
idTInformation à stocker dans le sommet.

Retour : un nouveau Vertex<T>.

let paris = Vertex::new("Paris");   // Vertex<&str>
let n42   = Vertex::new(42);        // Vertex<i32>

Précisions​

  • Identifiant interne ≠ id. Dans un Graph, un sommet est désigné par sa position dans Graph::vertex (un usize). C'est cet indice qu'utilisent les arêtes et les méthodes comme degree.
  • Pas d'unicité. Rien n'empêche deux sommets d'avoir le même id : ils restent distincts car ils n'ont pas le même indice.
  • Pas de voisins stockés. Un sommet ne connaît ni ses voisins ni son degré : ces informations sont calculées par le graphe à partir de ses arêtes (voir Graph::degree).
