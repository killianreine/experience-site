Graph — le graphe

Graph<T> représente un graphe : un ensemble de sommets de type Vertex<T>, un ensemble d'arêtes et la liste de ses propriétés (GraphType).

Fichier : src/model/graph.rs — contient aussi les énumérations GraphType et Degree.

Structure Graph<T>​

Définition​

src/model/graph.rs
#[derive(Debug)]
pub struct Graph<T> {
    pub graph_type: Vec<GraphType>, // Types du graphe
    pub vertex: Vec<Vertex<T>>,     // Sommets du graphe
    pub edges: Vec<Edge>,           // Arêtes du graphe
}

Champs​

ChampTypeVisibilitéDescription
graph_typeVec<GraphType>pubPropriétés du graphe. Un graphe peut en cumuler plusieurs (ex. orienté et pondéré).
vertexVec<Vertex<T>>pubSommets du graphe. L'indice d'un sommet dans ce vecteur est son identifiant interne.
edgesVec<Edge>pubArêtes du graphe, dont les extrémités sont des indices dans vertex.

Traits dérivés​

TraitEffet
DebugAffichage complet du graphe avec {:?} ou {:#?} (si T: Debug).
Créer un graphe

On peut construire un Graph directement avec ses champs publics, mais il est conseillé de passer par build_graph, qui vérifie que toutes les arêtes désignent des sommets existants.

Méthodes​

is​

pub fn is(&self, t: GraphType) -> bool

Indique si le graphe possède la propriété t, c'est-à-dire si t est présent dans graph_type.

ParamètreTypeDescription
tGraphTypePropriété recherchée.

Retour : true si graph_type contient t, false sinon.

if g.is(GraphType::Oriented) {
    println!("Le graphe est orienté");
}

out_degree​

pub fn out_degree(&self, v: usize) -> usize

Calcule le degré sortant du sommet d'indice v : le nombre d'arêtes dont v est la source.

ParamètreTypeDescription
vusizeIndice du sommet dans vertex.

Retour : le nombre d'arêtes telles que source == v.

in_degree​

pub fn in_degree(&self, v: usize) -> usize

Calcule le degré entrant du sommet d'indice v : le nombre d'arêtes dont v est la destination.

ParamètreTypeDescription
vusizeIndice du sommet dans vertex.

Retour : le nombre d'arêtes telles que destination == v.

degree​

pub fn degree(&self, v: usize) -> Degree

Calcule le degré du sommet d'indice v, adapté au type du graphe :

  • graphe orienté (GraphType::Oriented présent) : Degree::Oriented(entrant, sortant) ;
  • graphe non orienté : Degree::Simple(entrant + sortant), le nombre total d'extrémités d'arêtes en v.
ParamètreTypeDescription
vusizeIndice du sommet dans vertex.

Retour : une valeur de Degree.

match g.degree(0) {
    Degree::Simple(d) => println!("degré {d}"),
    Degree::Oriented(d_in, d_out) => println!("entrant {d_in}, sortant {d_out}"),
}

Complexité​

Les arêtes étant stockées dans une simple liste, chaque calcul de degré parcourt toutes les arêtes.

MéthodeComplexitéDétail
isO(k)k = nombre de types dans graph_type (très petit en pratique).
out_degreeO(|E|)Un parcours de edges.
in_degreeO(|E|)Un parcours de edges.
degreeO(|E|)Deux parcours de edges.

Calculer le degré de tous les sommets coûte donc O(|V| × |E|).

Précisions​

  • Indice hors limites. Les méthodes de degré ne vérifient pas que v désigne un sommet existant : avec un indice trop grand, elles renvoient simplement 0 (aucune arête ne correspond), sans erreur.
  • Boucles. Dans un graphe non orienté, une boucle (source == destination == v) est comptée deux fois dans Degree::Simple, une fois comme entrée et une fois comme sortie. C'est la convention habituelle en théorie des graphes.
  • Graphe non orienté. Une arête Edge::new(a, b, w) augmente de 1 le degré de a et celui de b, quel que soit l'ordre des extrémités.

Énumération GraphType​

Les propriétés qu'un graphe peut avoir. Le champ Graph::graph_type en contient une liste, ce qui permet de les combiner.

Définition​

src/model/graph.rs
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum GraphType {
    Default,  // Graphe simple
    Oriented, // Graphe orienté
    Weighted, // Graphe pondéré
}

Variantes​

VarianteSignificationEffet actuel
DefaultGraphe simple : non orienté, non pondéré.Aucun : c'est l'absence de Oriented qui rend un graphe non orienté.
OrientedGraphe orienté : chaque arête va de source vers destination.Change le résultat de degree (Degree::Oriented).
WeightedGraphe pondéré : le poids des arêtes a un sens.Indicatif : le poids est toujours stocké dans Edge::weight.

Traits dérivés​

Debug, Clone, Copy (la valeur est copiée, pas déplacée), PartialEq et Eq (comparaison avec ==, utilisée par is).

Combinaisons usuelles​

graph_typeGraphe obtenu
vec![GraphType::Default] ou vec![]non orienté, non pondéré
vec![GraphType::Oriented]orienté, non pondéré
vec![GraphType::Weighted]non orienté, pondéré
vec![GraphType::Oriented, GraphType::Weighted]orienté et pondéré
Pas de contrôle de cohérence

Rien n'empêche aujourd'hui d'écrire vec![GraphType::Default, GraphType::Oriented] ou de répéter un même type : graph_type est une simple liste. Le graphe sera alors considéré comme orienté, puisque is(GraphType::Oriented) renvoie true.

Énumération Degree​

Le degré d'un sommet, tel que renvoyé par Graph::degree. Sa forme dépend du type du graphe.

Définition​

src/model/graph.rs
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum Degree {
    Simple(usize),          // degré total
    Oriented(usize, usize), // (entrant, sortant)
}

Variantes​

VarianteDonnéesUtilisée pour
Simple(d)d : degré totalun graphe non orienté
Oriented(d_in, d_out)d_in : degré entrant, d_out : degré sortantun graphe orienté

Traits​

  • Dérivés : Debug, Clone, Copy, PartialEq, Eq.
  • std::fmt::Display (implémenté à la main) : permet d'afficher un degré avec {}.
ValeurAffichage avec {}
Degree::Simple(3)3
Degree::Oriented(1, 2)entrant 1, sortant 2
println!("degré de Paris : {}", g.degree(0));
// graphe orienté   → degré de Paris : entrant 0, sortant 2
// graphe non orienté → degré de Paris : 2
