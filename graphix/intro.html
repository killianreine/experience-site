Graphix

Beta1.0

Créer, visualiser, modifier et parcourir des graphes, à la souris dans une application ou par le code avec une bibliothèque.

État du projet

Graphix est en cours de conception. Cette documentation s'enrichira au fil de l'avancement du projet.

Deux parties, un même graphe​

Graphix se compose de deux parties pensées ensemble. On peut explorer un graphe à la main, puis passer au code pour aller plus loin, sans changer d'outil ni de graphe.

Visuel

L'application

Construire un graphe, le déplacer, le transformer et l'explorer directement sous les yeux.

  • Pour quiconque veut construire et explorer un graphe.
  • Comment en manipulant le graphe à la souris.
Code

La bibliothèque

Programmer ses propres algorithmes sur des graphes, au-delà de ce que propose l'application.

  • Pour quiconque veut écrire et exécuter ses algorithmes.
  • Comment en écrivant du code.

Comment les parties s'articulent​

L'application et la bibliothèque travaillent sur le même graphe : ce que l'on dessine peut être repris par le code, et inversement.

Glisser pour déplacer · Ctrl + molette pour zoomer

Ce qui est disponible​

La bibliothèque, écrite en Rust, pose les premières briques :

  • les modèles d'un graphe : sommet Vertex, arête Edge et graphe Graph ;
  • les types de graphes (simple, orienté, pondéré) et le calcul du degré des sommets ;
  • la création d'un graphe avec vérification de ses arêtes.
